## §R 前置·自托管 runner 注册与拉起（runner 生命周期 SOP）

> 判活总纲：**进程存在为第一证据 + runners API 复核为第二证据，缺一即处置**（前科：PID 在而 session 死=「API online 残影」假活）。本地服务化（NT 服务）需管理员授权，挂账未办——现行标准=用户会话后台拉起。
>
> **速查（两问直答，20261001 增补）**：全新装机=**R1 config 注册**（registration-token 经 API 直取→bsdtar 解压→`config.cmd --unattended` 免交互）→**R2 后台拉起**（`cd /d/actions-runner && cmd //c run.cmd`，Conflict 90-120s 自愈窗后等 `Listening for Jobs`）；日常掉线=**R3 判活双证**→**R4/R6 重新后台重拉**（run.cmd 先行——已配置态禁重复 config.cmd，仅目录损毁/注册失效才升 R1 全新注册）。

**R1 · 全新注册（config 注册）**——E627 全链七步：
1. registration-token 经 API 直取（`git credential fill` 的 PAT 即可，免网页）；
2. release 下载走国内镜像链轮询 + `curl -C -` 断点续传，完整性=API `assets[].size` 逐字节比对；
3. **解压必须 `/c/Windows/System32/tar.exe`（bsdtar）——Git Bash GNU tar 不认 zip=exit 2 假「损坏」**；
4. 注册：`config.cmd --unattended`（免交互）；
5. 判活双证建立后进 R2。

**R2 · 后台拉起（run.cmd 双斜杠铁律）**：
```
cd /d/actions-runner && cmd //c run.cmd     ← 后台拉起标准式
```
- **`//c` 双斜杠铁律**：Git Bash 单 `/c` 被 MSYS 路径转换吃掉=交互 cmd 假成功 exit 0 而 runner 实未起；
- 拉起后监听确认：Conflict 90-120s 自愈属正常 → 等 `Listening for Jobs` 字样；
- **换拉起方式=PATH 翻面**：schtasks 等方式拉起继承系统 PATH（System32 前置）→ workflow 裸名 `shell: bash` 解析到 WSL 桩→`HCS_E_HYPERV_NOT_INSTALLED` 秒红（34 秒、`|| true` 防护兜不住）——现 workflow 已固化显式全路径 `C:/Progra~1/Git/bin/bash.exe -e {0}` 免疫，但**任何换拉起方式须复查一切裸名解析**（bash/python/coqc）。

**R3 · 判活双证（每会话开工必查）**：
1. 进程存在：`tasklist` 见 `Runner.Listener.exe`；
2. API 复核：runners API `status:online`（`busy:true` 旗标可能陈旧不构成不推理由）；
- 仅进程在=可疑（前科 PID 1016 长闲置掉线死）；仅 API online=可能残影——双证齐才算活。

**R4 · 掉线重拉配方（长闲置掉线死）**：`taskkill` 旧 PID（确认非活 session）→ R2 重拉 → Conflict 自愈窗等待 → `Listening for Jobs` 确认。**checkout 层 443 连不上≠runner 死**（接单即证存活，禁重拉防双实例——网络窗走探针制导 rerun）。

**R5 · queued 滞死（入队竞态）**：run queued>5min + job runner=None + 无新 Worker 日志 + Listener 进程在 = 消息被死 session 消费——**光等无效，cancel+rerun**（盯守席 API 只读上报，修复属写操作经主会话）。

**R6 · 重拉判据树（20260928 增补——run.cmd 先行，config 仅限损毁态）**：判活双证（R3）全死时按序处置，禁跳级：
1. **先走 R2 run.cmd 后台重拉**（已配置态标准处置）：`cd /d/actions-runner && cmd //c run.cmd`——**已配置态禁重复 config.cmd**（防双实例/注册冲突）；拉起后 90-120s Conflict 自愈窗＋`Listening for Jobs` 字样确认（R2 全套铁律照用：`//c` 双斜杠、换拉起方式复查裸名解析）；
2. **仅当 run.cmd 拉不起才升级 R1 全新注册**（判据=目录损毁〔runner 目录残缺〕/注册失效〔config 凭证丢失、Listener 起后即退无监听〕）：registration-token 经 API 直取 → `config.cmd --unattended` → 回 R2 拉起（E627 全链七步照走）。
- 口径：未试 run.cmd 直接上 config.cmd=违规重注册（双实例/注册冲突风险源）。

**L11 · 在用运行体锁死律（v2.4.3 20261107 新立——20261105-06 桌面整理判例沉淀）**：凡在用 runner 目录、工具链区与会话运行体（现役会话赖以运行的可执行体及其备份体）**在用期一律锁死——禁移动、禁改名、禁删除**；桌面整理等清整作业开工前先核在用运行体清单，命中件一律跳过并登记禁迁（判例：在用备份体 ZCode-3.16.3-backup.app 两度被清整批量误迁候审区、两度回搬原位收场——清整批量不识别运行体在用性；工具链区 mac93_install_work 同在锁死清单）。运行体迁移仅限退役态（判活双证 R3 全灭＋退役登记后），在用期任何「先移走再说」＝现役会话/CI 作业源断裂源。

**L12 · runner 服务重启 env 复刻律（v2.4.3 20261107 新立——苹果侧 CI 爆红 run#220 判例·20261107 晨）**：runner 服务/服务壳**重启后必须先复刻工具链 env 导出再接单**——原实例 env 由启动壳携带，重启换壳即丢；点名核账六变量：`COQCHK/COQC/COQDEP/COQLIB/ROCQLIB/MAC_ROCQ93_ROOT`。判例链：mac 道 coqchk 步 `$COQCHK` 走 runner 进程继承 env→重启壳未带 9.3 工具链导出→coqchk 二进制空缺（cpu_guard.sh:73 `command not found`）未真跑→日志无 Axioms 段（NO_AXIOMS_SECTION）→gate banner＋gate2 fail-loud 连坐红（run#220·build 步 461 模块全过＝非数学问题）。处方＝重启时以全量 9.3 env 重拉（六变量逐一在卷·`MAC_ROCQ93_ROOT` 指 mac93_install_work/opam93/rocq93）→探针 run 验证 `Listening`＋六变量齐备→再放行真实作业。
