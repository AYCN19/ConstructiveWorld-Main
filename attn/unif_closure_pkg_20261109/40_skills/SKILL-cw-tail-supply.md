### §12.1 消费位量级六式 grep 专扫律（「语句面 earn≠消费位清」）

洗波完成（语句面全 Set 化）≠债清：洗面引理的**裸消费层**（下游以旧面战术消费新面结论）是独立的第二本账，语句面扫描/编目子集**结构性不可见**。判例（campaign 级证伪）：S12 预备席「60 站编目·债纯在消费位 58 站」被首炮第一手探针**证伪**——树代 real_*_proj 系＋sc_/b5n_/qeq_imp_qle 等全部洗面引理的裸消费层全文件 **478 行**未被编目覆盖，真债 ≈**530 站**（478＋58＝S11 量级）；1659 交叉表「余 33 名零改」同被证伪作废。**预算禁以编目子集外推**——消费位量级必须六式专扫定谳后再定席位数。六式 grep（对工作副本全文·洗面引理族名代入 `<族>`）：

2. `setoid_rewrite ` 裸调（QeqT 无 setoid 注册·S11 中账 61 站最大族群判例）；

4. `exact \(` 项位裸供家（结论桥漏裹·`exact (QleT'_to_Qle _ _ (H…))` 形补桥）；
5. `apply [A-Za-z_]*<族>` 直 apply（结论面失配）；

### §12.2 两向门选律六条＋q_neq match 正典

双向桥两副面孔形似对称实各认一结论面（`qeqT_imp_qeq` vs `qeq_imp_qeqT`·`QltT_to_Qlt` vs `Qlt_to_QltT`）——方向凭猜必翻车。六条（全文与判例链见 cw-ci-sop §1·H）：①**先定目标面**：Id 裹（`Id (Qle_bool…)`）=Set 面／`Gt -> False` 形=Prop 面；②**开门口诀「门名前半=手里证来源面·后半=目标面」**：目标 QeqT→`apply qeq_imp_qeqT`·目标 Qeq→`apply qeqT_imp_qeq`；③**裹桥禁 term 形 apply**：`rewrite (qeqT_imp_qeq _ _ 件)` 合法·`(qeqT_imp_qeq _ _ 件)` 直接 apply **禁用**（elaboration 先于目标统一·`_ _` 变不可解 evar·S122/124 判例）→改三战术链（开门→apply 件→补前提）；④**QltT 两参显式**：`QltT_to_Qlt _ _`/`Qlt_to_QltT _ _` 禁省参；⑤**NatLe 双桥**：`NatLe_drop _ _`（可 lia）/`NatLe_lift _ _`（S01:L100）；⑥**三面纠缠先勘实质面**：stdlib-Qle（Gt->False）/QleT'（Id(Qle_bool)）/Qle——`QleT'_to_Qle`/`Qle_to_QleT'` 先勘后选。
**q_neq_of_lt match 正典（exact 直闭两代废案）**：q_neq_of_lt 结论＝世界 Set 版 `Not` codomain 非 Empty_set 直闭形——S10 甲乙原方/S11 尾账原方两代 `exact` 直闭均废（探针定谳）；正典＝`intro Hz; apply qeq_imp_qeqT in Hz; apply (q_neq_of_lt <x> <Hprem>) in Hz; destruct Hz` 或 match 形（S11 援2 正典 L9998/L11110 实证·S12 F3 十站照抄）；Hyp 为 Qlt 面则 `Qlt_to_QltT` 单层提升禁双层。**供家实签第一手律**：一切引理结论面/参序以世界件 `grep -A8 'Lemma <name>'` 第一手实签为准——禁凭 Main 旧忆/行文想象签名（「==面想象签名」系统病·S10 乙席 26 括号雷同席判例）；正本直改前先勘 enclosing assert 目标面（Qle 目标→前桥 `QleT'_to_Qle`·QleT' 目标→零改）。

### §12.3 交割账条三病防呆＋静态判读探针仲裁律

**交割账三病**（S11 z11 探针席逮获三缺陷·逐病防呆）：①**漏结论桥**——账条只配前桥漏结论桥（判例 acct 3851）②**误删行**——配账 diff 误删邻行（判例 acct 6100 误删 Qabs_opp 行）③**裸名不合成**——账条给裸名未给全参合成形（判例 acct 6100/6335 同型）。**防呆三闸**：账条必带 old 串逐字＋count 断言＋new 串**全形**（合成形非裸名）；收割席对可疑账条**收割前探针/复验**——跳原方改援账修正形并通报账主（账本冻结不回改·修正记收口炮账互证）。
**静态判读探针仲裁律**：一切**静态判读**（范本/交叉表/编目账量/「零改」判词）可被廉价探针证伪，探针即仲裁——三判例：S12 编目「60 站」被首炮探针证伪（真债 530）／1659 交叉表「33 名零改」被证伪／尾席编目 L1081 范本（三拍形 ring 于 QeqT 面）被探针证伪（**ring 禁触 QeqT**——`qeq_imp_qeqT. ring.` 184 绿本实证→半桥 ring 尾=漏结论桥实债）。律：静态判读入账前先隔离探针一发（~2min）；探针红=静态误判定谳·该静态账降级「候选」禁直采；判读冲突以探针/编译第一手为最高仲裁。

### §12.4 批量裹桥工装化四要件

裸消费密集区（数百站级）逐站手裹不可行——**工装脚本一发批裹**（判例：S12 `_s12_wrap_bridge.py` 一发 14 站·336 括号＋59 裸名过闸·嵌套注释感知）。工装四要件：
1. **嵌套注释感知**：`*)` 首现扫界=Coq 嵌套注释破——扫描界须括号平衡＋注释深度感知；多行调用（多行 setoid_rewrite）按平衡括号扫描原生兼容·禁按行处理；
2. **四断言必开**：双名断言/新行断言/括号配平断言/count 断言——twin 行同文双现 count==1 过严·应 **count>=1 全裹**（每现皆站）；
3. **器坑三防**（处方内嵌）：op 指名尾非括号（group(0) 尾字符是名）→晚闭腐蚀；模板多写 group(2)→名双生；新行/断言缺省=静默腐蚀源；
4. **幂等**：已裹段重跑跳过（头区已闭段勿重裹——重跑浪费非错误）。
**执行纪律**：编辑恒前台·编译单独后台（后台 python 静默失败陷阱两踩判例——断言败→文件未改→炮打旧文）；行数断言必须动态（删桥站改变全文件行数·陈旧常数断言必败）；collision 字段制（对头部已炮站 skip-if-applied 防重复施刀）。
